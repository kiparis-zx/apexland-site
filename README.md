# ApexLand — вход через Twitch и заявка на сервер

Готовый сайт на Node.js без внешних пакетов. После входа через Twitch показывает форму с полями из образца: имя, подтверждённый Twitch-ник, Minecraft-ник, наличие лицензии и согласие с правилом честной игры. Каждому Twitch-аккаунту доступна одна заявка. Сайт также содержит справочник модификаций, правила и отдельную панель заявок для администратора.

## Быстрый запуск

Нужен Node.js 20.12 или новее.

```powershell
Copy-Item .env.example .env
npm start
```

Откройте `http://localhost:3000`. Пока Twitch не настроен, на стартовой странице есть кнопка **«Посмотреть демо формы»**. Демо-заявка не записывается в файл.

## Подключение Twitch

1. Создайте приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps).
2. Добавьте точный OAuth Redirect URL: `http://localhost:3000/auth/callback` для локального запуска.
3. Скопируйте Client ID и Client Secret в `.env`:

   ```dotenv
   TWITCH_CLIENT_ID=ваш_client_id
   TWITCH_CLIENT_SECRET=ваш_client_secret
   PUBLIC_URL=http://localhost:3000
   PORT=3000
   ```

4. Перезапустите сервер. Теперь кнопка входа перенаправит на Twitch, а после подтверждения вернёт к анкете.

Для публичного сайта с единым Node-сервером укажите `PUBLIC_URL=https://ваш-домен` и зарегистрируйте у Twitch `https://ваш-домен/auth/callback`. Запускайте с `NODE_ENV=production` за HTTPS-прокси. Секрет приложения храните только на сервере и не добавляйте `.env` в репозиторий.

## GitHub Pages и отдельный API

GitHub Pages размещает только файлы из `public/`. Для Twitch OAuth, заявок и панели администратора нужен постоянно работающий Node-сервер с постоянным диском. Схема для ApexLand: GitHub Pages обслуживает `https://aeromolica.kiparis.fun`, а Node-сервер — `https://api.aeromolica.kiparis.fun`. На сервере укажите `PUBLIC_URL=https://api.aeromolica.kiparis.fun`, `FRONTEND_URL=https://aeromolica.kiparis.fun`, `NODE_ENV=production` и добавьте в Twitch Developer Console точный Redirect URL `https://api.aeromolica.kiparis.fun/auth/callback`.

В опубликованном `public/config.js` задайте `window.APEX_API_ORIGIN = 'https://api.aeromolica.kiparis.fun';`. Браузер отправляет запросы с учётными данными на API; API разрешает CORS только для `FRONTEND_URL`. Поддомены должны оставаться под одним регистрируемым доменом, чтобы браузер передавал cookie входа. У API должен быть действительный HTTPS-сертификат. Админ-логин и пароль выводятся в консоль Node-сервера при каждом запуске.

Не помещайте `TWITCH_CLIENT_SECRET`, `.env` или файл `data/applications.json` в GitHub Pages или репозиторий. Переменные `PUBLIC_URL` и `PORT` для локального запуска должны указывать на один и тот же порт.

## Куда попадают заявки

Реальные заявки сохраняются в `data/applications.json` рядом с `server.mjs`. Путь можно изменить переменной `DATA_FILE`. Файл создаётся автоматически. Его содержимое не доступно через сайт; папка `data` исключена из Git.

Данные заявки: Twitch ID и ник, имя, Minecraft-ник, наличие лицензии, подтверждение правила и время отправки. Доступ на сервер после заявки выдаётся администратором отдельно.

## Панель администратора

Откройте `/admin`. При **каждом запуске** сервера в его консоль выводятся новый логин и пароль для панели. Они действуют до следующего перезапуска; после перезапуска нужно использовать новые данные. Не публикуйте вывод консоли с паролем. Панель показывает все реальные заявки, количество игроков с лицензией и без неё, а также поиск по игроку и Twitch. Демо-заявки в ней не отображаются.

## Моды и правила

Список на странице `/mods` адаптирован по [списку PepeLand](https://www.pepeland.net/rules/mods): FreeCam не входит в разрешённые и остаётся в запрещённых; Bedrock Miner удалён из запрещённых и не объявлен разрешённым. По спорным модификациям указаны модераторы Discord: `therhythmikkk`, `privatekey`, `.kiparis_`. Поиск работает по названиям и примечаниям.

Страница `/rules` содержит шесть разделов и 23 пункта из предоставленного файла правил. Из отображаемого текста удалены служебные пометки `[cite: 22]`. Текст правил описывает автоматическую привязку Minecraft UUID, сквозные блокировки Twitch/Minecraft/Discord и смену ника в личном кабинете. Эти технические функции в текущей версии сайта ещё не реализованы; пока сайт сохраняет заявку для ручной обработки администрацией.

## Структура

- `server.mjs` — OAuth, сессии, проверка формы, сохранение заявок и доступ администратора.
- `public/` — интерфейс и локальные графические материалы.
- `public/mods.js` — содержимое справочника модификаций и поиск.
- `public/admin.js` — список заявок в панели администратора.
- `public/assets/landscape-loop.mp4` — зацикленный видеозадник; `voxel-landscape.png` служит постером.

Сессии хранятся в памяти одного процесса, поэтому после перезапуска потребуется снова войти через Twitch. Для нескольких серверных экземпляров понадобится общее хранилище сессий и заявок.

Фоновая воксельная иллюстрация сгенерирована встроенным imagegen по запросу: «широкий кинематографичный воксельный пейзаж на закате — лес, река, горы и освещённая деревянная башня; без людей, текста, логотипов и интерфейса». Видео создано из этой иллюстрации плавным зацикленным смещением камеры.
